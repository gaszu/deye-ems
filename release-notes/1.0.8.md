# Deye EMS 1.0.8 — zapis wyboru CT

Naprawiono zapis trybu pomiaru z panelu. Wersja 1.0.7 odrzucała tekstową wartość `load_with_external_ct` na etapie walidacji WebSocket, zanim mogła trafić do ustawień. Pozostawiony w panelu wybór był niezapisanym szkicem, dlatego aktywacja nadal wymagała LOAD.

- API przyjmuje tekstowe wartości opcji, zachowując walidację konkretnej opcji w koordynatorze.
- Panel pokazuje oddzielnie zapisany tryb EMS i niezapisaną zmianę.
- Zachowano wymaganie zgodności modelu z rzeczywistym trybem falownika. Zapis CT konfiguruje EMS; nie przełącza fizycznego trybu falownika ani nie uruchamia sterowania.

Sprawdzenia offline: 376 testów Python i 67 testów panelu PASS, w tym przejście zapisu CT przez schemat API, przeładowanie koordynatora i aktywacja z poprawnymi syntetycznymi pomiarami oraz rozróżnienie udanego i odrzuconego zapisu w interfejsie. Testy nie dowodzą fizycznej reakcji falownika.

Po aktualizacji uruchom ponownie HA, wybierz CT w obserwacji, zapisz i sprawdź w panelu „Zapisany tryb EMS: Zero Export To CT”. Następnie zweryfikuj przypisania oraz aktualność pomiarów CT i portu GRID przed włączeniem sterowania.
