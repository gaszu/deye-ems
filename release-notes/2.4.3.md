# Deye EMS 2.4.3

Panel rozróżnia brak zapasu mocy przyłącza od limitu portu GRID falownika. Testy obejmują limit fazowy oraz limit łączny trójfazowego przyłącza.

The panel distinguishes utility connection headroom from the inverter GRID port limit. Regression tests cover both total and per-phase limits on a three-phase connection.
