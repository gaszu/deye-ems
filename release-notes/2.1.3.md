# Deye EMS 2.1.3 — poprawne datowanie raportów ESPHome

- Naprawiono użycie starszego potwierdzenia pary jako czasu bieżącej wartości. Po dwóch poprawnych raportach jednej sesji najnowszy rzeczywisty odbiór wyznacza jej świeżość i podlega dotychczasowej kontroli zgodności czasowej; starszy odbiór potwierdzający parę jest sprawdzany osobno.
- Zachowano wymaganie dwóch raportów, ich dopuszczalny wiek, zgodność najnowszej wartości z HA, kontrolę urządzenia i przypisania oraz unieważnianie po przerwie przekraczającej limit wieku, rozłączeniu, cofnięciu zegara lub zmianie źródła. Nowa para musi przejść dotychczasową bramkę po zdarzeniu.
- Opis diagnostyki odróżnia świeżość najnowszego odbioru od potwierdzenia pary. Żaden znacznik odbioru nie dowodzi chwili pomiaru Modbus ani fizycznego działania falownika.

Nie podniesiono limitów świeżości ani rozbieżności czasowej. Sterownik, planer, taryfy, rezerwa SoC, limity, przypisania i wygląd panelu pozostają zachowane. Aktualizacja nie wymaga zmian firmware. [Przejście i powrót](https://github.com/gaszu/deye-ems/blob/v2.1.3/MIGRATION.md).
