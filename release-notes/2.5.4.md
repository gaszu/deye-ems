# Deye EMS 2.5.4

Kafelki układu na głównym panelu pokazują osobno moc portu GRID i przyłącza z kierunkiem przepływu oraz pomiarami fazowymi. Pozostałe kafelki pokazują moc domu i odbiorów między GRID a CT. W układzie LOAD panel pokazuje port GRID i dom.

The main panel displays metering tiles with separate GRID and utility totals, flow directions and phase readings. In LOAD mode it shows the GRID and home tiles.
