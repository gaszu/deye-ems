# Deye EMS 2.0.4 — zgodność encji aktualizacji

Naprawiono błąd dodawania encji **Deye EMS — Nowe wydanie** w Home Assistant 2026.11. Wydanie 2.0.3 przekazywało zwykłą liczbę `0` jako listę możliwości; HA wymaga typu `UpdateEntityFeature`. Encja używa teraz pustego zestawu flag: nadal tylko informuje o wydaniu, bez instalowania i restartowania HA.

Automatyczny kontroler wydań i panel zachowują dotychczasowy harmonogram. Test regresji odtwarza sprawdzanie przynależności flag wykonywane przez HA podczas dodawania encji, które dla zwykłej liczby powodowało `TypeError`.

Po poprawnym, jawnym przywróceniu sterowania usuwany jest wyłącznie historyczny komunikat nieudanego wznowienia podczas startu. Nie zmienia to wymagań aktywacji ani innych błędów, limitów, przypisań lub ustawień produkcyjnych.

Wersja 2.0.3 pozostaje opublikowana bez zmian. Aktualizacja 2.0.4 wymaga ponownego załadowania integracji przez restart HA.

Walidacja offline: **687 testów Python i 173 testy panelu PASS**. Testy nie zastępują sprawdzenia załadowanej wersji i dostępności encji po wdrożeniu.
