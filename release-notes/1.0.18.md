# Deye EMS 1.0.18 — jasny stan doładowania i przyczyna oczekiwania

Ogólny komunikat „Nastawa utrzymywana do :00 lub :30” zastępuje informacja o stanie doładowania baterii z sieci. Panel rozróżnia włączone i wyłączone Grid Charge, zapisany limit prądu oraz brak potwierdzenia.

Oczekiwanie na stabilne pomiary, potwierdzenie nastawy, pierwszy start lub zwykły termin korekty jest opisane oddzielnie. Dokładny najwcześniejszy termin pochodzi z backendu, z uwzględnieniem bieżących warunków; panel nie zgaduje go z zegara. Brak albo nieaktualność danych nie potwierdzają włączenia ładowania.

Diagnostyka wskazuje pomiary, które nie przeszły dotychczasowej walidacji. Informacja pomaga odróżnić przerwę po utracie danych od zwykłego utrzymania nastawy. Sam odczyt Grid Charge i dodatniej nastawy nie jest pomiarem energii pobranej z sieci do baterii.

Zmiana dotyczy prezentacji i diagnostyki. Zachowuje decyzje regulatora, harmonogram zapisów, limity, rezerwę SoC i istniejące ustawienia. Zakres sprawdzeń opisuje [VALIDATION.md](../VALIDATION.md).
