# Deye EMS 2.7.7

Pole komunikatów otwiera natywne okno encji Komunikat silnika. Recorder zapisuje stany tej encji od jej utworzenia. Własne okna encji otwierają też bieżący SoC, wybrany cel SoC, automatyczny limit ładowania Deye i dostępny prąd ładowania. Obsługa pozostałych wartości panelu jest w przygotowaniu.

The message area opens the native Home Assistant entity dialog. Recorder saves the message entity’s states from its creation. Current SoC, selected SoC target, the automatic Deye charging limit and available charging current also link to their own entities. Other panel values are not covered by this release.
