# Deye EMS 2.1.0 — operatorzy, taryfy i start po zapisie

Katalog obejmuje pięciu OSD: PGE Dystrybucja, TAURON Dystrybucja, Enea Operator, Energa Operator i PGE Energetyka Kolejowa. Dostępnych jest 30 zweryfikowanych profili; dwie pozycje wymagające brakujących reguł regionalnych lub dynamicznych pozostają zablokowane. Własny harmonogram G13 jest zachowany do osobnego wyboru i potwierdzenia nowego profilu.

Panel prowadzi przez operatora, taryfę, jawny wybór zegara i podgląd przed zapisem. Kalendarz oraz cele SoC korzystają z rzeczywistych przedziałów, sezonu, dni tygodnia i świąt. Rozdzielono strefy operatora od sześciu technicznych wpisów TOU. Minione lub nieznane projekcje pozostają puste, a cele zachowawcze mają wyraźny opis.

Po końcowym zapisie kreator źródeł, modelu, Solcast albo taryfy zamyka się automatycznie. Manager w HA sprawdza nową konfigurację, pomiary, plan i zabezpieczenia przed wznowieniem sterowania. Działa również przy zamkniętej przeglądarce. Ręczny STOP anuluje oczekujący start. Brak potwierdzenia odczytów wyłączenia doładowania przed przeładowaniem blokuje dalszy krok.

Przycisk sterowania jest na górze panelu. Komunikat ostatniej nieudanej akcji nie znika po odświeżeniu; można go zamknąć bez usuwania bieżących alarmów silnika. Limity mocy i prądu, ochrona rezerwy, źródła oraz firmware urządzeń pozostają zachowane przy aktualizacji.

Źródła i warunki profili: [TARIFFS.md](../TARIFFS.md). Przejście i powrót: [MIGRATION.md](../MIGRATION.md). Poprzednie wydania pozostają niezmienione.

Walidacja offline: **798 testów Python i 206 testów panelu PASS**. Dodatkowy przegląd kompilacji sprawdził 1080 kombinacji profili, dat i zegarów; nie potwierdza fizycznego działania wszystkich firmware.
