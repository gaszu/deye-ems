# Deye EMS 1.0.11 — licznik zapytań Solcast

W sekcji prognozy PV panel pokazuje osobno **Wykorzystano**, **Limit** i **Pozostało** oraz czas odnowienia doby UTC przeliczony na czas Warszawy.

- Licznik dotyczy prób własnego klienta API EMS, w tym błędów i zaimportowanego wykorzystania. Nie jest liczbą udanych pobrań ani potwierdzeniem wykorzystania całego konta przez inne aplikacje.
- Brak danych, stary odczyt, poprzednia doba i nieprawidłowy stan licznika są jawnie oznaczone, bez fikcyjnego zera. Wyłączony lub nieskonfigurowany klient oraz źródło z encji HA mają osobne wyjaśnienia.
- Odczyt panelu nie odpytuje Solcasta i nie zmienia rejestru wykorzystania. Status udostępnia jedynie bezpieczne flagi konfiguracji i włączenia API.
- Wydanie zachowuje źródło prognozy, limit zapytań, ustawienia sterowania i wygląd panelu.

Zakres walidacji opisuje [VALIDATION.md](../VALIDATION.md).
