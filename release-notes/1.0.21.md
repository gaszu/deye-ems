# Deye EMS 1.0.21 — nowy adres repozytorium

Repozytorium integracji ma adres **https://github.com/gaszu/deye-ems**. Nazwa wyświetlana pozostaje „Deye EMS”, a domena integracji i zapisane encje to nadal `deye_ems`.

Zaktualizowano przyciski instalacji Marketplace, dokumentację, odnośniki do wydań, klienta sprawdzania aktualizacji i warunek publikacji GitHub Actions. Istniejące repozytorium zachowuje identyfikator, historię i wydania; poprzednie adresy korzystają z przekierowań GitHub. Nie usuwaj wpisu integracji ani jej ustawień podczas aktualizacji.

Zmiana nie modyfikuje planowania, sterowania falownikiem, źródeł danych ani parametrów baterii. Testy i kontrole HACS/hassfest pozostają wymagane przed publikacją. Zgłoszenie do katalogu Marketplace otrzymuje nowy adres repozytorium.
