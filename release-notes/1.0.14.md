# Deye EMS 1.0.14 — typ układu zawsze widoczny

Główny panel zawsze pokazuje sekcję **Układ LOAD** albo **Układ LOAD i CT**, zgodnie z zapisaną konfiguracją. Sekcja pozostaje widoczna także przy braku aktualnych pomiarów.

- W obu układach dostępne są natywny pomiar wyjścia LOAD, kierunek przepływu przez port GRID, odczyt trybu falownika i opis wspólnej mocy urządzenia.
- W układzie LOAD i CT panel dodatkowo pokazuje wymianę z siecią na CT oraz obliczony pobór odbiorów między GRID a CT. Pomiar CT i port GRID mają różne znaczenie i są opisane oddzielnie.
- W układzie LOAD pobór odbiorów między GRID a CT jest oznaczony jako nieobliczany. Domyślne zero modelu nie jest przedstawiane jako pomiar braku takich odbiorów.
- Nieaktualne, nieprawidłowe lub niezgodne z zapisaną topologią odczyty zastępuje informacja o braku danych. Prawidłowa wartość zero pozostaje widoczna.

Zmiana dotyczy prezentacji danych. Zachowuje konfigurację, źródła pomiarów, tryb pracy i algorytm sterowania. Sprawdzenia obu układów wykonano offline; ich wyniki opisuje [VALIDATION.md](../VALIDATION.md).
