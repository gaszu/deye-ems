# Deye EMS 1.0.4

Przycisk **Połącz i skonfiguruj Solcast** otwiera teraz kreator bezpośrednio w panelu EMS. Wcześniej prowadził jedynie do ogólnej strony integracji, bez otwarcia ustawień.

- Ręczna konfiguracja, import z obecnej integracji Solcast i wyłączenie pobierania przez EMS korzystają z istniejącego natywnego options flow HA, jego walidacji i zapisu. Import zachowuje prywatny szkic do czasu zatwierdzenia formularza.
- Zmiana połączenia wymaga jawnego przejścia do obserwacji. Otwarcie lub anulowanie kreatora oraz sama aktualizacja wersji nie przełączają źródła prognozy. Powrót do sterowania pozostaje osobną czynnością po uzyskaniu poprawnego planu.
- Zapis ręcznej konfiguracji włącza pobieranie API; może ono zużyć limit konta. Wyłączenie ma osobne potwierdzenie. Zapisany klucz nie jest przesyłany do panelu, a klucz wpisywany w otwartym formularzu pozostaje tylko w jego pamięci i jest czyszczony przy zakończeniu lub zamknięciu.
- Zachowano ograniczenia zapytań i import współczynników. Import nie wyłącza poprzedniego klienta Solcast i nie przenosi jego dalszego samouczenia.
- Panel otrzymał stonowane pastelowe przyciski, oznaczenia i wykres. Kolory korzystają ze zmiennych motywu HA, zachowując czytelność w jasnym i ciemnym interfejsie.

Poprawka nie zmienia algorytmu ładowania, parametrów ani specyfikacji silnika 1.0.0. Zestaw sprawdzeń opisuje [VALIDATION.md](../VALIDATION.md).
