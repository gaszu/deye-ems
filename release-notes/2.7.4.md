# Deye EMS 2.7.4

Przy starcie EMS aktualizuje adres istniejącego zasobu karty Lovelace do wersji zainstalowanej integracji. Dotyczy zasobu dodanego w interfejsie Home Assistanta. Zasobami YAML zarządza administrator.

At startup EMS refreshes an existing storage-managed Lovelace card resource to match the installed integration version. YAML resources remain administrator-managed.
